1. The Core Idea: Local Router Architecture

            

              SLProxy runs locally on :8080, acting as a high-performance routing bridge between your AI coding tools and multiple backend providers.
            

          


          
          

            
Architecture Overview:

            

              

                
Coding Tools

                
Claude Code, Cursor, OpenCode, Codex

              

              

                
SLProxy (:8080)

                
Router & Python Plugins

              

              

                
AI Backends

                
Antigravity, OpenAI, Anthropic, Local

              

            

          


          
    
            
  • 
              
              Unified Endpoints: Single URL for both OpenAI (/v1/chat/completions) and Anthropic (/v1/messages).
            
    • 
            
  • 
              
              Zero Lock-in: Switch models, inject headers, or failover without touching your IDE configuration.
            
    • 
          

        


        
        

          

            
2. Provider Plugins with < 1s Hot Reload

            

              Every provider in SLProxy is an editable, isolated Python plugin. Change token interceptors, request headers, or quota detection logic live in your browser with instant hot reload.
            

          


          

            

              

                
                Reference Templates
              

              

                Install pre-built plugins for OpenAI Codex, Claude Code, Google Antigravity, OpenRouter, and Ollama with 1 click.
              

              
            


            

              

                
                Custom Python Code
              

              

                Subclass BasePlugin. Custom headers, quota parsers, and stream transformations reload in < 100ms.
              

              
            

          


          

            
            No server restarts required — hot reload deploys changes instantly.
          

        


        
        

          

            
3. Multi-Account Routing & Failover

            

              Add multiple API keys per provider to eliminate rate limits, tier throttling, and token quotas.
            

          


          

            

              

                Priority Fallback (Recommended)
                Default
              

              

                Always routes to Priority 1 account first. When an account receives an HTTP 429 or quota limit, SLProxy automatically puts it into cooldown and routes to Priority 2 instantly.
              

            


            

              Weighted Round-Robin
              

                Distributes high-volume concurrency across all active accounts proportionally to their configured weights.
              

            

          


          

            Cooldown Recovery:
            Automatic background ticker (1s)
          

        


        
        

          

            
4. Secure Local Router Keys

            

              Generate isolated local keys (slp-live-...) for individual coding tools or automated agents.
            

          


          

            

              
Quota Limits

              
Cap max requests or max tokens per key.

            

            

              
Model Scoping

              
Restrict keys to specific models or providers.

            

            

              
Expiration

              
Set 7-day, 30-day, or permanent tokens.

            

          


          

            Example Bearer Header:
            

              Authorization: Bearer slp-live-cursor-e9182ab47c8d901f
              
            

          

        


        
        

          

            
5. Connect Your AI Tools

            

              Copy and paste the configuration snippet for your primary coding environment:
            

          


          
          


            
            

              

                Claude Code (Anthropic CLI)
                
              

              
export ANTHROPIC_BASE_URL=http://localhost:8080/routerapi
export ANTHROPIC_API_KEY=slp-live-demo

            


            
            

              

                Cursor IDE (OpenAI Override)
                
              

              

                
Base URL: http://localhost:8080/routerapi/v1

                
API Key: slp-live-demo (or any local key)

              

            


            
            

              

                OpenCode / Codex CLI
                
              

              
export OPENCODE_BASE_URL=http://localhost:8080/routerapi/v1
export OPENCODE_API_KEY=slp-live-demo

            


            
            

              

                cURL (Raw HTTP Request)
                
              

              
curl -X POST http://localhost:8080/routerapi/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer slp-live-demo" \
  -d '{"model": "default-model", "messages": [{"role": "user", "content": "Hello"}]}'
